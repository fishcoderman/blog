# 性能测试

性能优化前后的渲染时间、滚动FPS、内存占用，这些指标是如何测试得来的？

## 1. 渲染时间测试

### 方法 A: Chrome DevTools Performance

```tsx
// 1. 打开 Chrome DevTools -> Performance 标签
// 2. 点击录制按钮
// 3. 刷新页面或触发渲染
// 4. 停止录制

// 查看指标：
// - Scripting (JS 执行时间)
// - Rendering (渲染时间)
// - Painting (绘制时间)
```

**具体步骤：**
1. 打开 DevTools (F12)
2. 切换到 **Performance** 标签
3. 点击录制 ⏺ 按钮
4. 刷新页面或执行操作
5. 停止录制
6. 查看火焰图中的 **Rendering** 时间

### 方法 B: React DevTools Profiler

```tsx
import { Profiler } from 'react';

  id: string,

  </IndexBar>

```

### 方法 C: Performance API (代码测量)

```tsx
// ✅ 组件外标记,测量从模块加载到渲染完成
performance.mark('component-load');

export default function IndexBarDemo() {
  const [isRendered, setIsRendered] = useState(false);
  
  useLayoutEffect(() => {
    if (!isRendered) {
      performance.mark('component-rendered');
      performance.measure(
        'total-time',
        'component-load',
        'component-rendered'
      );
      
      const measure = performance.getEntriesByName('total-time')[0];
      console.log(`总时间: ${measure.duration.toFixed(2)}ms`);
      setIsRendered(true);
    }
  }, [isRendered]);

  return <IndexBar>...</IndexBar>;
}
```

## 2. 滚动 FPS 测试

### 方法 A: Chrome DevTools Rendering

```
1. 打开 DevTools (F12)
2. 按 Cmd+Shift+P (Mac) 或 Ctrl+Shift+P (Windows)
3. 输入 "Show Rendering"
4. 勾选 "Frame Rendering Stats" (FPS meter)
5. 滚动页面，观察 FPS 显示
```

**读取指标：**
- **FPS**: 当前帧率（60fps 为流畅）
- **Frame time**: 每帧耗时（16.7ms 以下为流畅）

### 方法 B: Performance Monitor

```
1. DevTools -> More tools -> Performance monitor
2. 查看实时 FPS
3. 滚动页面观察 FPS 变化
```

### 方法 C: 代码测量 (requestAnimationFrame)

```tsx
function useFPSMonitor() {
  useEffect(() => {
    let frameCount = 0;
    let lastTime = performance.now();
    let fps = 0;

    function measureFPS() {
      frameCount++;
      const currentTime = performance.now();
      
      // 每秒计算一次 FPS
      if (currentTime >= lastTime + 1000) {
        fps = Math.round((frameCount * 1000) / (currentTime - lastTime));
        console.log(`当前 FPS: ${fps}`);
        
        frameCount = 0;
        lastTime = currentTime;
      }
      
      requestAnimationFrame(measureFPS);
    }

    const rafId = requestAnimationFrame(measureFPS);
    return () => cancelAnimationFrame(rafId);
  }, []);
}

// 使用
export default function Test() {
  useFPSMonitor(); // 实时监控 FPS
  return <IndexBar>...</IndexBar>;
}
```

**完整的 FPS 测试组件：**

```tsx
import React, { useEffect, useRef, useState } from 'react';

export function FPSMonitor() {
  const [fps, setFps] = useState(60);
  const frameCountRef = useRef(0);
  const lastTimeRef = useRef(performance.now());

  useEffect(() => {
    let rafId: number;

    function measure() {
      frameCountRef.current++;
      const currentTime = performance.now();
      const elapsed = currentTime - lastTimeRef.current;

      if (elapsed >= 1000) {
        const currentFps = Math.round((frameCountRef.current * 1000) / elapsed);
        setFps(currentFps);
        frameCountRef.current = 0;
        lastTimeRef.current = currentTime;
      }

      rafId = requestAnimationFrame(measure);
    }

    rafId = requestAnimationFrame(measure);
    return () => cancelAnimationFrame(rafId);
  }, []);

  return (
    <div
      style={{
        position: 'fixed',
        top: 10,
        right: 10,
        padding: '8px 12px',
        background: fps < 30 ? '#f44336' : fps < 50 ? '#ff9800' : '#4caf50',
        color: 'white',
        borderRadius: 4,
        fontSize: 14,
        fontWeight: 'bold',
        zIndex: 9999,
      }}
    >
      FPS: {fps}
    </div>
  );
}
```

## 3. 内存占用测试

### 方法 A: Chrome DevTools Memory

```
1. 打开 DevTools -> Memory 标签
2. 选择 "Heap snapshot"
3. 点击 "Take snapshot" 拍摄快照
4. 在优化前后分别拍摄快照
5. 对比 "Shallow Size" 和 "Retained Size"
```

**步骤：**
1. 优化前：加载页面 → 拍摄快照 A
2. 优化后：加载页面 → 拍摄快照 B
3. 对比快照，查看内存差异

### 方法 B: Performance Memory

```
1. DevTools -> Performance 标签
2. 勾选 "Memory" 选项
3. 录制性能
4. 查看内存曲线（蓝色线）
```

### 方法 C: Performance.memory API

```tsx
function useMemoryMonitor() {
  useEffect(() => {
    const interval = setInterval(() => {
      // @ts-ignore - performance.memory 是非标准 API
      if (performance.memory) {
        const { usedJSHeapSize, totalJSHeapSize, jsHeapSizeLimit } = performance.memory;
        
        console.log('内存使用情况:');
        console.log(`- 已使用: ${(usedJSHeapSize / 1048576).toFixed(2)} MB`);
        console.log(`- 总分配: ${(totalJSHeapSize / 1048576).toFixed(2)} MB`);
        console.log(`- 限制: ${(jsHeapSizeLimit / 1048576).toFixed(2)} MB`);
      }
    }, 2000);

    return () => clearInterval(interval);
  }, []);
}
```

**内存监控组件：**

```tsx
export function MemoryMonitor() {
  const [memory, setMemory] = useState({ used: 0, total: 0 });

  useEffect(() => {
    const updateMemory = () => {
      // @ts-ignore
      if (performance.memory) {
        // @ts-ignore

        });
      }
    };

    const interval = setInterval(updateMemory, 1000);
    return () => clearInterval(interval);
  }, []);

  return (
    <div style={{ position: 'fixed', top: 50, right: 10, background: '#333', color: '#fff', padding: 8 }}>
      内存: {memory.used} MB / {memory.total} MB
    </div>
  );
}
```

## 4. DOM 节点数测试

### 方法 A: Chrome DevTools Elements

```javascript
// 在 Console 中执行
document.querySelectorAll('*').length  // 总 DOM 节点数
document.querySelectorAll('.adm-list-item').length  // 列表项数量
```

### 方法 B: Performance Observer

```tsx
function useDOMNodeCount() {
  useEffect(() => {
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        console.log('DOM 节点统计:', entry);
      }
    });

    // 观察 DOM 变化
    const domObserver = new MutationObserver(() => {
      const nodeCount = document.querySelectorAll('*').length;
      const listItems = document.querySelectorAll('.adm-list-item').length;
      console.log(`总节点: ${nodeCount}, 列表项: ${listItems}`);
    });

    domObserver.observe(document.body, {
      childList: true,
      subtree: true,
    });

    return () => {
      observer.disconnect();
      domObserver.disconnect();
    };
  }, []);
}
```

## 完整的性能测试套件

创建一个完整的测试组件：

```tsx
// performance-test-suite.tsx
import React, { useEffect, useState, useRef } from 'react';

export function PerformanceTestSuite({ children }: { children: React.ReactNode }) {
  const [metrics, setMetrics] = useState({
    renderTime: 0,
    fps: 60,
    memory: 0,
    domNodes: 0,
  });

  const frameCountRef = useRef(0);
  const lastTimeRef = useRef(performance.now());
  const renderStartRef = useRef(performance.now());

  useEffect(() => {
    // 1. 测量渲染时间
    const renderTime = performance.now() - renderStartRef.current;

    // 2. 监控 FPS
    let rafId: number;
    function measureFPS() {
      frameCountRef.current++;
      const currentTime = performance.now();
      const elapsed = currentTime - lastTimeRef.current;

      if (elapsed >= 1000) {
        const currentFps = Math.round((frameCountRef.current * 1000) / elapsed);
        frameCountRef.current = 0;
        lastTimeRef.current = currentTime;

        // 3. 测量内存
        // @ts-ignore
        const memory = performance.memory
          ? // @ts-ignore
            Math.round(performance.memory.usedJSHeapSize / 1048576)
          : 0;

        // 4. 统计 DOM 节点
        const domNodes = document.querySelectorAll('*').length;

        setMetrics({
          renderTime,
          fps: currentFps,
          memory,
          domNodes,
        });
      }

      rafId = requestAnimationFrame(measureFPS);
    }

    rafId = requestAnimationFrame(measureFPS);
    return () => cancelAnimationFrame(rafId);
  }, []);

  return (
    <>
      {/* 性能指标显示 */}
      <div
        style={{
          position: 'fixed',
          top: 10,
          right: 10,
          background: 'rgba(0,0,0,0.8)',
          color: '#fff',
          padding: 12,
          borderRadius: 4,
          fontSize: 12,
          fontFamily: 'monospace',
          zIndex: 9999,
        }}
      >
        <div>🚀 渲染时间: {metrics.renderTime.toFixed(2)}ms</div>
        <div style={{ color: metrics.fps < 30 ? '#f44336' : '#4caf50' }}>
          📊 FPS: {metrics.fps}
        </div>
        <div>💾 内存: {metrics.memory} MB</div>
        <div>🌳 DOM 节点: {metrics.domNodes}</div>
      </div>

      {children}
    </>
  );
}
```

**使用：**
```tsx
import { PerformanceTestSuite } from './performance-test-suite';

export default function TestPage() {
  return (
    <PerformanceTestSuite>
      <IndexBar>
        {/* 你的大数据列表 */}
      </IndexBar>
    </PerformanceTestSuite>
  );
}
```

## 实际对比测试流程

### 测试脚本

```tsx
// 1. 生成测试数据
const generateTestData = (count: number) => {
  return Array(count).fill(0).map((_, i) => ({
    id: i,
    name: `Item ${i}`,
  }));
};

// 2. 测试优化前
function TestBefore() {
  const data = generateTestData(1200);
  
  return (
    <PerformanceTestSuite>
      <IndexBar>
        <IndexBar.Panel index="A" title="A">
          <List>
            {data.map(item => (
              <List.Item key={item.id}>{item.name}</List.Item>
            ))}
          </List>
        </IndexBar.Panel>
      </IndexBar>
    </PerformanceTestSuite>
  );
}

// 3. 测试优化后
function TestAfter() {
  const data = generateTestData(1200);
  
  return (
    <PerformanceTestSuite>
      <IndexBar>
        <IndexBar.Panel index="A" title="A">
          <IndexBar.VirtualList
            items={data}
            itemHeight={45}
            maxHeight={300}
            renderItem={(item) => <List.Item>{item.name}</List.Item>}
          />
        </IndexBar.Panel>
      </IndexBar>
    </PerformanceTestSuite>
  );
}
```
