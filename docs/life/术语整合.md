# 术语整合

以下是高频英文简写术语分类整理，涵盖架构、技术、设计模式等领域：

## 1. 前端高频术语

• 架构与框架  

  • SPA：Single Page Application（单页应用）  

  • SSR：Server-Side Rendering（服务端渲染）  

  • MVVM：Model-View-ViewModel（前端架构模式）  

  • MVC：Model-View-Controller（分层架构模式）  

• 性能与优化  

  • LCP：Largest Contentful Paint（最大内容渲染时间）  

  • FCP：First Contentful Paint（首次内容渲染时间）  

  • TTI：Time to Interactive（首次可交互时间）  

  • Tree Shaking：移除未使用代码的优化技术  

  • Lazy Loading：延迟加载非关键资源  

## 2. 后端高频术语

• 架构与设计  

  • SOA：Service-Oriented Architecture（面向服务的架构）  

  • MVC：Model-View-Controller（分层架构模式）  

  • DDD：Domain-Driven Design（领域驱动设计）  

  • ORM：Object-Relational Mapping（对象关系映射）  

• 数据库与存储  

  • SQL：Structured Query Language（结构化查询语言）  

  • NoSQL：非关系型数据库  

  • ACID：数据库事务四大特性（原子性、一致性、隔离性、持久性）  

• 网络与协议  

  • HTTP：HyperText Transfer Protocol（超文本传输协议）  

  • HTTPS：HTTP Secure（加密版HTTP）  

  • REST：Representational State Transfer（RESTful API设计风格）  

  • RPC：Remote Procedure Call（远程过程调用）  

• 开发模式与工具  

  • API：Application Programming Interface（应用程序接口）  

  • SDK：Software Development Kit（软件开发工具包）  

  • CI/CD：Continuous Integration/Continuous Deployment（持续集成/部署）  

  • Docker：容器化技术  

  • K8s：Kubernetes（容器编排工具）  

## 3.通用与跨领域术语

• 编程范式  

  • OOP：Object-Oriented Programming（面向对象编程）  

  • AOP：Aspect-Oriented Programming（面向切面编程）  

  • FP：Functional Programming（函数式编程）  

• 设计模式  

  • DI：Dependency Injection（依赖注入）  

  • IoC：Inversion of Control（控制反转）  

  • Singleton：单例模式  

• 安全与运维  

  • JWT：JSON Web Token（身份验证令牌）  

  • CORS：Cross-Origin Resource Sharing（跨域资源共享）  

  • XSS：Cross Site Scripting（跨站脚本攻击）  

  • CSRF：Cross Site Request Forgery（跨站请求伪造）

## 4. 通用管理与运营

• SOP：Standard Operating Procedure（标准操作程序）  

• ROI：Return on Investment（投资回报率）  

• KPI：Key Performance Indicator（关键绩效指标）  

• OKR：Objectives and Key Results（目标与关键成果法）  

• SWOT：Strengths, Weaknesses, Opportunities, Threats（SWOT分析）  

## 5.财务与投资

• GMV：Gross Merchandise Volume（商品交易总额）  

• CPA：Cost Per Action（按行动成本，如广告投放）  

• CPC：Cost Per Click（按点击成本，如搜索引擎广告）  

• CPM：Cost Per Mille（按千次展示成本，如广告计费）  

• LTV：Lifetime Value（用户生命周期价值）  

## 6. 市场与用户

• DAU：Daily Active User（日活跃用户）  

• MAU：Monthly Active User（月活跃用户）  

• UV：Unique Visitor（独立访客）  

• PV：Page View（页面浏览量）
