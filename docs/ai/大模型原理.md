<p>从基础开始，一步一步带你了解一个大语言模型（LLM）是如何诞生的。你会看到一个“从文本 → 模型 → 智能输出”的完整流程，就像训练一个AI“语言小脑”的过程。</p>

<h2>🧠 目标：从 0 理解 LLM 的 7 个核心阶段</h2>
<p>我们用通俗语言讲解每一阶段的原理、作用和关键概念。</p>

<h2> 阶段 1：Tokenization（分词）</h2>
<p><strong>目标：把「人类语言」变成「数字」</strong></p>
<p>📝 举个例子：</p>
<pre><code class="language-text">输入句子：I love AI.
</code></pre>
<p>要让模型能理解，它得变成数字，比如：</p>
<pre><code>"I" → 103
"love" → 412
"AI" → 987
"." → 27
</code></pre>
<h3>有哪些常用 Tokenizer？</h3>
<ul>
<li>
<p><strong>字符级</strong>（小模型）：每个字符是一个 token → <code inline="">["I", " ", "l", "o", "v", "e"]</code></p>
</li>
<li>
<p><strong>单词级</strong>：一个词是一个 token</p>
</li>
<li>
<p><strong>BPE（Byte Pair Encoding）</strong>（主流）：将高频子词组合成 token，例如 <code inline="">["un", "lik", "ely"]</code></p>
</li>
<li>
<p><strong>SentencePiece</strong> / <strong>Tokenizer by OpenAI（tiktoken）</strong>：高效，支持子词、空格、标点等编码方式</p>
</li>
</ul>

<h2> 阶段 2：构建模型结构（Transformer）</h2>
<p><strong>目标：构建能理解句子关系的神经网络</strong></p>
<p>核心是 <strong>Transformer 架构</strong>，最早来自论文《Attention is All You Need》。</p>
<h3>基本组成：</h3>
<ul>
<li>
<p><strong>Embedding 层</strong>：把 token 数字转为向量，比如 103 → [0.23, -0.8, ...]</p>
</li>
<li>
<p><strong>位置编码</strong>：告诉模型每个词的位置顺序</p>
</li>
<li>
<p><strong>Self-Attention</strong>：让每个词都能“关注”句子中其他词（比如 "not happy" 中，"not" 影响了 "happy"）</p>
</li>
<li>
<p><strong>MLP 层</strong>：做最终的特征提取和预测</p>
</li>
<li>
<p><strong>Residual &amp; LayerNorm</strong>：帮助训练稳定</p>
</li>
</ul>
<p>🔁 多个 Transformer Block 叠在一起，就能“更深地理解”语言含义。</p>

<h2> 阶段 3：训练循环（输入、输出、损失函数）</h2>
<p><strong>目标：让模型通过看大量文字，学会「预测下一个词」</strong></p>
<p>训练方法非常简单，但高效：</p>
<pre><code class="language-text">输入：I love
目标：love AI
</code></pre>
<p>每次让模型预测下一个词是什么，如果预测错了，就调整模型内部参数（反向传播）。</p>
<h3>损失函数：</h3>
<ul>
<li>
<p>通常用 <strong>交叉熵（Cross Entropy Loss）</strong></p>
</li>
<li>
<p>越接近真实的词，Loss 越低</p>
</li>
</ul>

<h2> 阶段 4：准备训练数据</h2>
<p><strong>目标：喂给模型「海量、高质量」文本</strong></p>
<p>常用的数据集：</p>
<ul>
<li>
<p>Wikipedia（百科全书）</p>
</li>
<li>
<p>BookCorpus（小说文本）</p>
</li>
<li>
<p>Common Crawl（互联网页面）</p>
</li>
<li>
<p>GitHub、Reddit、新闻等</p>
</li>
</ul>
<p>特点：</p>
<ul>
<li>
<p><strong>越多越好</strong>（LLM通常训练几百 GB ~ TB 级数据）</p>
</li>
<li>
<p><strong>清洗质量很关键</strong>（去广告、乱码等）</p>
</li>
</ul>
<p>数据通常要变成 token 编号后才能送进模型训练。</p>

<h2> 阶段 5：模型训练（大脑学习）</h2>
<p><strong>目标：真正让模型「从文本中学习语言规律」</strong></p>
<p>你可以理解为：“大脑开始读书，逐渐变聪明”</p>
<p>技术细节：</p>
<ul>
<li>
<p><strong>优化器</strong>：通常用 AdamW（适合 NLP）</p>
</li>
<li>
<p><strong>多 GPU 并行</strong>：分布式训练</p>
</li>
<li>
<p><strong>混合精度训练（FP16）</strong>：更快，省显存</p>
</li>
<li>
<p><strong>梯度裁剪</strong>：防止爆炸</p>
</li>
</ul>
<p>训练几小时到几周不等，依规模而定。</p>

<h2> 阶段 6：推理 &amp; 采样（模型输出）</h2>
<p><strong>目标：让模型「写出新句子」或「回答问题」</strong></p>
<p>流程：</p>
<ol>
<li>
<p>给模型输入开头 → “I love”</p>
</li>
<li>
<p>模型预测下一个词 → “you”</p>
</li>
<li>
<p>把预测结果接到输入上，再次预测下一个 → “so”</p>
</li>
<li>
<p>重复直到达到长度或遇到结束符</p>
</li>
</ol>
<h3>常见采样方式：</h3>

方法 | 说明
-- | --
Greedy | 每次选概率最大的
Top-k | 只在前 k 个最高概率中选
Top-p（nucleus） | 在累计概率达到 p 的词中随机选
温度 sampling | 加 randomness，控制创造性
