# 大模型原理

从 0 理解大语言模型（LLM）：7 个核心阶。

> 目标：用通俗、系统的方式，带你从零认识 LLM 的工作原理与训练推理流程。

本文围绕 7 个阶段展开：

- 阶段 1：Tokenization（分词）
- 阶段 2：模型结构（Transformer）
- 阶段 3：训练任务与损失（下一词预测）
- 阶段 4：数据准备与预处理
- 阶段 5：模型训练（优化与工程）
- 阶段 6：推理与采样（生成文本）
- 阶段 7：对齐与增强（SFT / RLHF / 工具使用）

## 阶段 1：Tokenization（分词）

- 目标：把人类语言变成模型可以处理的「离散数字序列」。
- 常见方式：
	- 字符级（Character-level）：每个字符一个 token，简单但序列长。
	- 词级（Word-level）：每个词一个 token，词表巨大且难泛化。
	- 子词级（Subword）：主流方案，如 BPE、SentencePiece、tiktoken。

示例（子词级）：
 
```text
输入："unlikely"
切分："un" + "lik" + "ely"
```

分词器输出 token id 序列，随后进入模型的 Embedding 层映射为向量。


## 阶段 2：模型结构（Transformer）

Transformer 是 LLM 的基础架构，核心组件包括：

- Embedding：把 token id → 向量
- 位置编码（Positional Encoding / RoPE）：注入序列位置信息
- 多头自注意力（Multi-Head Self-Attention）：建模长程依赖
- 前馈网络（Feed-Forward/MLP）：非线性特征变换
- 残差连接与层归一化（Residual + LayerNorm）：稳定训练

多个 Transformer Block 堆叠形成深层网络，增强表示与推理能力。


## 阶段 3：训练任务与损失（下一词预测）

- 预训练任务：给定前缀，预测下一个 token（Causal Language Modeling）。
- 形式化：最大化真实序列的对数似然，等价于最小化交叉熵损失。

简单例子：
 
```text
输入（上下文）：I love
目标：            love AI
```

模型逐步学习语言统计规律与世界知识。

## 阶段 4：数据准备与预处理

- 数据来源：Wikipedia、Books、Common Crawl、代码、论坛、新闻等。
- 关键点：

	- 规模：数百 GB 到 TB 级别更常见。
	- 清洗：去重、去广告、去乱码、过滤低质内容。
	- 采样与配比：不同域数据按权重混合，控制分布。
	- 分词与打包：转为 token，构造固定长度训练样本（含跨段续接）。


## 阶段 5：模型训练（优化与工程）

- 优化器：AdamW 为主，配合学习率预热与余弦退火等调度。
- 并行策略：数据并行、模型并行、流水线并行、张量并行。
- 混合精度：FP16/BF16 提升吞吐、降低显存。
- 稳定性：梯度裁剪、防止梯度爆炸；检查 NaN；损失平滑/正则化。
- 检查点与评估：定期保存权重与在验证集上打分，避免过拟合。

训练耗时与成本与模型规模、数据规模、硬件条件强相关。

## 阶段 6：推理与采样（生成文本）

给定提示（Prompt），模型自回归地产生下一个 token：

- Greedy：每步取最大概率；确定性高，易陷入平庸。
- Top-k：只在概率前 k 的候选中采样。
- Top-p（Nucleus）：在累计概率达到 p 的候选集合中采样。
- 温度（Temperature）：调节分布“平滑度”，越高越有创造性。

实际中常组合使用，如 temperature + top-p。

## 阶段 7：对齐与增强（SFT / RLHF / 工具使用）

在预训练基础上进一步“对齐人类意图”和“增强能力”：
- SFT（监督微调）：用人工标注或高质量多轮对话数据进行有监督微调。
- RLHF（从人类反馈中强化学习）：
	1) 收集多候选回复，人工打分；
	2) 训练奖励模型（RM）；
	3) 用 PPO/DPO 等方法优化生成模型。
- RAG（检索增强生成）：接入向量检索，把外部知识注入上下文，降低幻觉。
- 工具使用（Tool Use / MCP）：让模型通过标准协议调用外部工具、读写资源。

## 常见问题与误区

- 是否需要“理解语义”？
	- 模型本质是概率分布估计器，但规模+数据+训练使其表现出强语义能力。
- 为什么会“幻觉”？
	- 训练目标是“似然最大化”，非事实性保证；需要 RAG、工具、校验约束。
- 大模型一定更好吗？
	- 任务相关。小模型+检索/工具往往更经济实用。
